## Adding Binary Numbers
   - `1011 + 1101 = 11000` (11 + 13 = 24)
   - `100110 + 101011 = 1010001` (38 + 43 = 81)
   - `11101 + 10111 = 110100` (29 + 23 = 52)

## Subtracting Binary Numbers
   - `1101 - 1010 = 11` (13 - 10 = 3)
   - `10110 - 1001 = 1101` (22 - 9 = 13)
   - `10001 - 1110 = 11` (17 - 14 = 3)

### Working

**Addition**

```
  1011        100110        11101
+ 1101      + 101011      + 10111
------      --------      ------
 11000       1010001       110100
```

**Subtraction**

```
  1101        10110        10001
- 1010      -  1001      -  1110
------      -------      -------
    11         1101           11
```

# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.

Hardware is the physical, tangible part of a computer system. It includes every component you can see and touch, such as the CPU, RAM, storage drives, motherboard, power supply, cooling fans, keyboard, mouse, and monitor. Hardware provides the mechanical, electronic, and electrical structure that lets a computer operate. Each device has a specific role: the CPU processes instructions, memory stores data temporarily, and storage keeps files permanently. Without hardware there would be nothing to run programs on, because software needs physical circuits and devices to execute its instructions.
---

## Explain Software
Write **at least 50 words** explaining what software is.

Software is the set of instructions, programs, and data that tell a computer what to do. It is intangible, meaning it cannot be touched, and it is stored as code on hardware. Software is usually divided into system software, such as the operating system and device drivers, and application software, such as browsers, games, and word processors. The operating system manages memory, files, and hardware resources, while applications perform tasks for the user. Software turns the raw electronic capability of hardware into useful, organised functions that people can actually use.
---

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact.

Hardware and software interact through a layered system of instructions and signals. When a user runs a program, the software sends instructions to the CPU, which fetches, decodes, and executes them using electrical signals on the circuits. The operating system acts as the bridge, translating high-level requests into low-level commands that the hardware understands. Data moves between the CPU, RAM, and storage over buses, while input and output devices exchange information through controllers and drivers. Good interaction depends on compatible drivers and a correct instruction set, so neither part is useful without the other.

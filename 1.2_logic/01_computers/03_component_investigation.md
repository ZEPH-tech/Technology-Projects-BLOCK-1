# Part 3 – Component Investigation
Photograph and investigate the following components.
Images should be stored in:
```
images/components/
```

| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU | Executes program instructions and performs arithmetic/logic operations; often called the "brain" of the computer. | Number of cores, clock speed (GHz), cache size, socket type |
| RAM | Temporary (volatile) working memory that stores data and instructions currently in use by running programs. | Capacity (e.g. 8/16 GB), type (DDR3/DDR4/DDR5), speed (MHz) |
| Storage | Permanently stores the operating system, applications, and user files even when power is off. | HDD or SSD, capacity (e.g. 256 GB/1 TB), interface (SATA/NVMe) |
| Motherboard | Main circuit board that connects and allows communication between CPU, RAM, storage, and peripherals. | Chipset, form factor (ATX/micro-ATX), supported sockets and RAM type |
| Power Supply | Converts mains AC power into the regulated DC voltages the components need. | Wattage (e.g. 500 W), efficiency rating (80 PLUS), connector types |
| Cooling | Removes heat produced by components to prevent overheating and throttling. | Air vs liquid cooling, fan size/RPM, heatsink material (aluminium/copper) |
